# 미국 카운티의 대기질, 생활비, 범죄율 분석 (개정판)

다음은 학사 졸업논문의 한국어 요약본입니다.
2025년 가을학기에 제출한 논문을 2026년 10월에 다시 분석한 개정판입니다.

- 소속: 조지메이슨대학교 Computational and Data Sciences 학사 졸업논문
- 지도교수: Dr. Kent Miller
- 사용 도구: R (dplyr, fixest, ggplot2), LaTeX
- 참여: 개인 연구

## 1. 연구 질문

사람들은 살 곳을 고를 때 범죄율, 생활비, 환경을 비교합니다. 이 연구는 세 가지를 물었습니다.

- 대기질이 좋은 지역은 범죄율이 낮은가?
- 생활비가 비싼 지역은 범죄율이 다른가?
- 여러 요인을 함께 고려하면 어떤 요인이 범죄율과 가장 강하게 관련되는가?

## 2. 데이터

- 출처: 미국 정부 자료를 모아 만든 공개 데이터셋(Kaggle)
- 범죄율(2016): FBI
- 대기질, 수질 위반 건수: EPA
- 생활비, 소득: EPI
- 실업률: USDA
- 인구: Census
- 분석 대상: 49개 주와 DC의 카운티 2892개

대기질은 주마다 값이 하나뿐이라, 전체 데이터에 서로 다른 값이 50개밖에 없습니다. 이 점이 이후 분석에서 중요했습니다.

## 3. 방법

- 카운티 범죄율을 결과변수로 회귀분석을 했습니다.
- 인구, 도시화, 소득, 실업률, 생활비/소득 비율을 통제했습니다.
- 같은 주 안의 카운티끼리는 비슷할 수 있어서, 표준오차를 주 단위로 묶어 계산했습니다(클러스터링).
- 주, 권역, 지구 단위 고정효과를 넣어 같은 지역 안에서만 비교하는 분석도 했습니다.

## 4. 주요 결과

처음 분석에서는 대기질과 생활비 모두 p < 10^(-16)으로 매우 유의하게 나왔습니다.
결과가 너무 좋아서 데이터 구조부터 다시 확인했고, 세 가지 착시를 찾았습니다. 다음과 같습니다.

**부풀려진 표본.** 주 단위 대기질 값 50개가 학교 8.7만 행에 복사돼 있어서 표본이 실제보다 커 보였습니다. 주 단위로 클러스터링하자 표준오차가 15배 커졌습니다.

**상쇄되는 교란.** 생활비가 비싼 지역은 소득이 높아서 범죄율이 낮아지는 쪽과, 도시적이라서 범죄율이 높아지는 쪽을 함께 가지고 있습니다. 두 효과가 서로 상쇄돼 생활비와 범죄율은 관계가 없었습니다(p = 0.62).

**지역을 대신한 변수.** 대기질이 나쁜 주는 대부분 서부와 남서부(CA, AZ, NM, CO, UT)였습니다. 같은 권역 안에서만 비교하자 대기질 효과가 사라졌습니다(p = 0.36).

가장 중요한 요인은 다음과 같습니다.

- 소득: 높을수록 범죄율이 낮았습니다. 소득이 10% 높으면 주민 1000명당 범죄가 약 2.6건 적었습니다.
- 인구 규모와 도시화: 클수록, 도시적일수록 범죄율이 높았습니다.
- 관계 없음: 실업률과 수질 위반 건수는 범죄율과 관련이 없었습니다.

## 5. 결론

범죄율과 가장 강하게 관련된 것은 생활비나 대기질이 아니라 소득과 도시화였습니다.
다만 한 시점의 지역 간 비교라서, 이 요인들이 범죄를 일으키거나 줄인다는 인과관계까지는 말할 수 없습니다.

방법론 측면에서는 "통계적으로 매우 유의한 결과"가 가짜일 수 있는 흔한 이유 세 가지를 한 데이터에서 확인했습니다.

- 같은 값을 여러 행에 반복한 경우
- 서로 반대 방향의 효과가 상쇄된 경우
- 넓은 지역 단위로 측정한 변수가 지리를 대신 측정한 경우

## 6. 배운 점

이 연구에서 가장 크게 배운 것은 결과가 좋게 나올수록 먼저 의심해야 한다는 점입니다.
처음 결과를 그대로 썼다면 틀린 결론을 냈을 것입니다.

실무에서도 같은 문제가 자주 생긴다고 생각합니다.
예를 들어 A/B 테스트에서 사용자 단위로 실험군을 나눠 놓고 클릭 단위로 분석하면, 첫 번째 착시와 같은 이유로 효과가 과장됩니다.
또 지역이나 우편번호 같은 변수가 다른 요인을 대신 설명하는 경우도 많아서, 변수 하나의 효과를 볼 때는 비교 범위를 바꿔 가며 확인하는 습관이 생겼습니다.
